================================================================
  iOS / ANDROID COMPANION
================================================================
Python and Tkinter cannot run on iOS, so I built the honest alternative:
JARVIS hosts a small web app on your Wi-Fi and your phone opens it like
an app.

1. Start JARVIS on the computer.
2. Settings > Phone Link > copy the http://<ip>:8765/?k=... link.
3. Open it in Safari, then Share > Add to Home Screen.

The phone gets text chat, the same British voice, dictation where Safari
supports it, a full-screen standalone layout, and safe-area support for
the notch and home bar. Every API call still needs the pairing token.
I did not fake "native iOS": I gave you the closest honest thing.
