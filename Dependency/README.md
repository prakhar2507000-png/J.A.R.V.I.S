# Dependency - the readable source

I am Prakhar. I left every module JARVIS uses in plain Python here on
purpose.

Open any file and read it. Change it, break it, fix it. That is how I
learned, and that is how this project is meant to be used.

Start JARVIS with `../JARVIS.py`, or use
`../1. START ME ONCE FIRST (IF ON WINDOWS).bat` (Windows) /
`../2. START ME ONCE FIRST (IF ON MAC).command` (macOS).

`jarvis_main.py` is the orchestrator. `jarvis_ui.py` is the interface.
`jarvis_guard.py` is the web shield. `jarvis_vault.py` is the Cipher Vault.
